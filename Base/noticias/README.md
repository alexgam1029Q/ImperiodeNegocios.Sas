# Noticias del juego

Esta carpeta contiene las noticias por sector que alimentan el simulador de mercado y la evolución del juego.

## Objetivo

Cada archivo representa un sector o industria dentro del mundo del negocio. Las noticias sirven para:

- mostrar cambios en el panorama económico
- influir en la percepción del mercado
- alimentar decisiones de inversión
- actualizar el contexto del juego por sector
